# Kaavika's Portfolio

A modern and responsive portfolio website built using Next.js to showcase my skills, projects, achievements, and contact information.

## Features

- Responsive design
- About Me section
- Skills showcase
- Project portfolio
- Contact form with EmailJS integration
- Smooth user experience

## Tech Stack

- Next.js
- React.js
- Tailwind CSS
- EmailJS

### Sales Forecasting and Demand Prediction
